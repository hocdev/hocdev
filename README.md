### 👨‍💻 About Me

I am a passionate **Full-Stack Developer** focused on building high-performance desktop software, developer tooling, and modern web applications. I love diving into systems programming with **Rust** and turning everyday problems into practical, open-source solutions.

- 🔭 **Currently building:** Lightweight desktop tools and system utilities (e.g., [LiteSQL](https://github.com/hocdev/LiteSQL), [RustForm](https://github.com/hocdev/RustForm)).
- 🌐 **Platform & Community:** Creator of [hocdev.com](https://hocdev.com) — sharing developer resources, programming tutorials, and utilities.
- 🌱 **Learning & Exploring:** Low-level systems programming, virtualization with QEMU, and modern Rust GUI architectures.
- 💬 **Ask me about:** Rust, Full-Stack Web Development, Slint UI, Microsoft SQL Server, and desktop app architecture.
- ⚡ **Fun fact:** Passionate about zero-bloat, portable tools that work smoothly out of the box!
